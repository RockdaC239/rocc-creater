# 自媒体封面 SOP · 大标题位于人物后方

上级：[内容生产工作流](../内容生产.md)。输入一张原照、四字大标题、最多三行的副标题，以及宽高比（默认 3:4）。交付 PNG 成品、预览、可编辑文字层和检查报告。仅在需要人物遮挡时保留透明人像与 Alpha Mask。

## 安装一次

在 Apple Silicon MacBook Air M4、24 GB 内存上验证。使用 arm64 Python 3.13、Node.js 22 或更高版本、npm、uv 和 Xcode Command Line Tools（`swiftc`）。若本机没有 uv，可用同一 Python 的 `-m venv .venv` 和 `.venv/bin/python -m pip install -r requirements.txt`。已按旧模板安装无界黑时可直接复用。

从工作区根目录运行：

```sh
npm ci --prefix 工具/穿插封面
(
  cd 工具/穿插封面
  uv venv --python 3.13
  uv pip install -r requirements.txt
)
mkdir -p ~/.cache/rocc-edit
if [ ! -s ~/.cache/rocc-edit/UnboundedSans-Regular.otf ]; then
  curl -L --fail https://cdn.jsdelivr.net/gh/maoken-fonts/unbounded-sans@main/fonts/UnboundedSans-Regular.otf \
    -o ~/.cache/rocc-edit/UnboundedSans-Regular.otf
fi
```

字体使用[无界黑（OFL）](https://github.com/maoken-fonts/unbounded-sans)和 macOS 的苹方简 Semibold（半粗体，字重600）。默认读取工具目录的 `.venv/bin/python`，也可将 `COVER_PYTHON` 指向已有环境。rembg 首次使用每个模型时下载约 1 GB 权重到本机模型缓存，之后可离线推理。先使用 macOS 自带 Apple Vision 检测人物与人脸框，首次会编译本地 Swift 检测器。检测区域与固定标题字形相交时才读取缓存或运行 rembg。无人或无重叠时直接合成。抠图由 ONNX Runtime 在 CPU 执行，默认 4 线程，可通过 `OMP_NUM_THREADS` 调整。照片处理和图层合成均在本机完成。依赖和模型来源见 [rembg](https://github.com/danielgatis/rembg)及 [Sharp](https://sharp.pixelplumbing.com/install/)。

## 制作与复核

1. 准备一张无标题、无参考框的原照。图 1 的橙框和白框只用于定义文字区，成品仅渲染文字和阴影。有人物时优先用头顶有留白、清晰正立的照片；无人照片同样可用。
2. 从工作区根目录执行：

   ```sh
   node 工具/穿插封面/render.mjs '本期/原照.jpg' '本地封面' \
     $'一张原图，自动排版\n让大标题藏到人物身后' '本期/封面_v1' --ratio 3:4
   ```

   输出目录必须是新版本目录。脚本校正图片方向，先在原图像素尺寸固定标题位置，检测人物区域是否与标题字形相交。无人或无重叠时按原图背景、大标题、副标题直接合成；相交时读取缓存或运行模型生成原尺寸人像与蒙版，再按原图背景、大标题、人像、副标题的层序合成。最终裁为目标比例下可容纳头部的最大整数画布。PNG 保留该画布的原始像素尺寸。
3. 查看 `preview.png` 和 `report.json`。脚本检查最小逐字可见率、头部估计范围和交叠处半透明像素比例，默认锁定标题在画布中的高度；交叠不足时保留位置并输出提示，过度遮挡或超出安全区则报错。显式启用自动定位模式后才尝试其他标题高度或上移裁切窗口。副标题过长时自动换行和缩字号。检测后仍放不下会报错。打开 `cover.png` 放大至 100%，确认标题可读、五官完整、穿插处发缘自然。人物预检使用检测框，发顶由人脸框向上扩展估计，存在误检或漏检的可能；分割后的检测依赖上部轮廓和蒙版半透明比例，语义可读性、细发丝、漏抠或背景误抠由预览复核。
4. 需要精修时保留上一版，使用下一节命令重渲染。验收后交付 `cover.png`。同时保留原分辨率的 `title.svg`、`subtitle.svg`。需要人物遮挡时另存 `portrait.png` 和 `alpha-mask.png`。SVG 字形已转路径，可独立查看和编辑。

## 改标题、切模型和修蒙版

2026-11-17 已确认图 2 的大标题效果。2026-11-21 修正为固定画布顶部锚点 `title.top=0.065`，1572px 高画布的字身顶部为102px。换照片时默认固定此位置；交叠不足会提示预览检查。后续穿插封面沿用模板的 `title` 参数及原阴影。

默认配置位于[模板 JSON](../../工具/穿插封面/template.json)。复制或写一份局部覆盖 JSON，然后用 `--config` 传入。相对字体文件路径相对于该配置文件，TTC 字体通过 `fontIndex` 选具体字面。

| 想调的参数 | JSON 字段 |
| --- | --- |
| 大标题横向中心、固定顶部 | `title.x`、`title.top`，分别以裁切宽、高为单位。默认顶部为画布高度的6.5%。显式设置 `top: null` 才启用按人像发顶自动定位，此时 `yOffset` 和 `overlapDepth` 生效 |
| 大标题字号、橙色、字体 | `title.size`（裁切宽度的比例）、`title.color`、`title.font`、`title.fontIndex` |
| 大标题穿插深度 | `title.overlapDepth`，首选位置向发缘下压的比例。在 `title.top=null` 的自动定位模式下越大越深，实际位置受安全区和逐字可见率约束 |
| 大标题最低可见率 | `title.minVisiblePerGlyph`，任一字低于门槛时会试其他高度 |
| 副标题 | `subtitle.y`、`size`、`color`、`font`、`fontIndex`、`lineHeight`。每行左对齐，默认在大标题字身左边界基础上右移裁切宽度的2.5%，由 `subtitle.xOffset` 控制。副标题字身底部留白至少等于大标题字身顶部留白 |
| 阴影 | 大标题沿用[原封面阴影](../../工具/封面版式.json)。副标题使用 `subtitle.shadowOpacity=0.8`、`subtitle.shadowBlur=8`，模糊按裁切宽度相对1917px缩放，在1179px宽成品上约4.92px。偏移同原配置 |

```sh
node 工具/穿插封面/render.mjs '本期/原照.jpg' '本地封面' \
  '只改标题，复用同一张人像蒙版' '本期/封面_v2' --config '本期/版式.json' --render-only
```

- 以原始照片字节和模型名索引蒙版，缓存默认位于 `~/.cache/rocc-edit/cover-masks/`，可用 `--cache-dir` 指定别处。改文案、排版和比例会复用同一蒙版。 `--render-only` 仅在检测到重叠且缺少可用蒙版时提示；无人或无重叠时直接出图。显式传入 `--mask` 表示使用人工确认的蒙版，会跳过检测。
- 发缘精修后将灰度 PNG 另存，白色代表前景、黑色代表背景，与校正方向后的照片尺寸一致。重渲染命令加 `--mask '本期/精修蒙版.png'`；也可直接传入上次导出的 `alpha-mask.png`。
- 人像模型效果不合适时，首次切换使用 `--model birefnet-general`，保持同一张原照并换新版本目录。两种模型缓存独立。实际选用的模型和蒙版来源见 `report.json`。
- “无法保留头部”时改用更宽松的比例。“无法同时实现穿插和保留字形”时尝试更宽的头顶留白，或调整大标题的横向位置、字号和蒙版。字体缺字时改用覆盖该字的字体。“三行放不下”时缩短副标题。
- 脚本向标准错误输出抠图、缓存、自动重排和导出日志，标准输出是检查报告 JSON。可用 `npm test --prefix 工具/穿插封面` 运行合成回归。


## 图 2 验收记录

2026-11-17 在 Apple M4、24 GB 机器上运行。测试文案为“本地封面”，使用图 2 原照。Portrait 版首次推理与套版约 12.8 秒（权重已下载），输出 1179×1572。4:5 改稿用同一蒙版，约 0.6 秒并自动上移标题，输出 1176×1470。General 版也完成首次推理和 3:4 导出。两种模型的 3:4 输出及缓存改稿均通过文字和阴影范围外的 sRGB 像素比对。Portrait 版查看了完整预览与发缘原尺寸局部。另验证 1:1 裁切会自动上移以保留标题，近景的副标题仍可能压到下巴，图 2 采用 3:4 作为成品。

2026-11-21 已验证无人纯色照片和人物远离标题照片均跳过抠像，缓存为空时也能完成渲染；教培新机原照在检测到相交后复用蒙版，标题保持102px。检测结果和实际分支写入报告的 `detection`、`needsMask`、`maskSource` 字段。

### 历史排版试验

2026-11-21 用户更新规则。同行所有文字与数字必须使用相同字号，异行可按信息重要性区分字号，默认全部使用苹方简Semibold。重点可用橙色强调。阴影80%、模糊约5px继续沿用。试稿v11把原先宽松的字身行间空隙收至22px（1179px宽），每行字号分别78、82、88px，保留上移后的文字区。默认均匀字号模板行高调整至1.1；逐行信息层级方案另存本期排版JSON，尚未接入通用渲染器。

副标题居中规则补充：逐行水平居中，同时将全部行的字身包围框作为整体，在固定副标题区内垂直居中。改变行数时重新计算整块高度，保持区域中心；禁止仅删除多余行而沿用首行位置。教培新机试稿的区域中心为画布(589.5,1249.17)，以1179×1572画布记录。
