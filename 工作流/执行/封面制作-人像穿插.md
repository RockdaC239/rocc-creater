# 自媒体封面 SOP · 大标题位于人物后方

上级：[内容生产工作流](../内容生产.md)。输入一张有头顶留白的单人原照、四字大标题、最多三行的副标题，以及宽高比（默认 3:4）。交付 PNG 成品、预览、可编辑文字层、透明人像、Alpha Mask 和检查报告。

## 安装一次

在 Apple Silicon MacBook Air M4、24 GB 内存上验证。使用 arm64 Python 3.13、Node.js 22 或更高版本、npm 和 uv。若本机没有 uv，可用同一 Python 的 `-m venv .venv` 和 `.venv/bin/python -m pip install -r requirements.txt`。已按旧模板安装无界黑时可直接复用。

从工作区根目录运行：

```sh
npm ci --prefix 工具/穿插封面
(
  cd 工具/穿插封面
  uv venv --python 3.13
  uv pip install -r requirements.txt
)
mkdir -p ~/.cache/rocc-edit
if [ ! -s ~/.cache/rocc-edit/UnboundedSans-Regular.otf ]; then
  curl -L --fail https://cdn.jsdelivr.net/gh/maoken-fonts/unbounded-sans@main/fonts/UnboundedSans-Regular.otf \
    -o ~/.cache/rocc-edit/UnboundedSans-Regular.otf
fi
```

字体使用[无界黑（OFL）](https://github.com/maoken-fonts/unbounded-sans)和 macOS 的冬青黑体简体中文 W6。默认读取工具目录的 `.venv/bin/python`，也可将 `COVER_PYTHON` 指向已有环境。rembg 首次使用每个模型时下载约 1 GB 权重到本机模型缓存，之后可离线推理。抠图由 ONNX Runtime 在 CPU 执行，默认 4 线程，可通过 `OMP_NUM_THREADS` 调整。照片处理和图层合成均在本机完成。依赖和模型来源见 [rembg](https://github.com/danielgatis/rembg)及 [Sharp](https://sharp.pixelplumbing.com/install/)。

## 制作与复核

1. 准备一张无标题、无参考框的原照。图 1 的橙框和白框只用于定义文字区，成品仅渲染文字和阴影。优先用头顶有留白、清晰正立的单人照。
2. 从工作区根目录执行：

   ```sh
   node 工具/穿插封面/render.mjs '本期/原照.jpg' '本地封面' \
     $'一张原图，自动排版\n让大标题藏到人物身后' '本期/封面_v1' --ratio 3:4
   ```

   输出目录必须是新版本目录。脚本校正图片方向，在原始像素尺寸生成灰度蒙版和透明人像。按原图背景、大标题、人像、副标题的层序合成，最终裁为目标比例下可容纳头部的最大整数画布。PNG 保留该画布的原始像素尺寸。
3. 查看 `preview.png` 和 `report.json`。脚本检查最小逐字可见率、头部估计范围和交叠处半透明像素比例，超限时依次尝试更合适的标题高度。若居中裁切挤掉头顶空间，会尝试上移裁切窗口。副标题过长时自动换行和缩字号。检测后仍放不下会报错。打开 `cover.png` 放大至 100%，确认标题可读、五官完整、穿插处发缘自然。自动检测依赖单人上部轮廓和蒙版半透明比例，语义可读性、细发丝、漏抠或背景误抠由预览复核。
4. 需要精修时保留上一版，使用下一节命令重渲染。验收后交付 `cover.png`。同时保留 `portrait.png`、`alpha-mask.png` 和原分辨率的 `title.svg`、`subtitle.svg`。SVG 字形已转路径，可独立查看和编辑。

## 改标题、切模型和修蒙版

2026-11-17 已确认图 2 的大标题效果。后续穿插封面默认沿用模板的 `title` 参数及原阴影。

默认配置位于[模板 JSON](../../工具/穿插封面/template.json)。复制或写一份局部覆盖 JSON，然后用 `--config` 传入。相对字体文件路径相对于该配置文件，TTC 字体通过 `fontIndex` 选具体字面。

| 想调的参数 | JSON 字段 |
| --- | --- |
| 大标题横向中心、纵向偏移 | `title.x`、`title.yOffset`，分别以裁切宽、高为单位 |
| 大标题字号、橙色、字体 | `title.size`（裁切宽度的比例）、`title.color`、`title.font`、`title.fontIndex` |
| 大标题穿插深度 | `title.overlapDepth`，首选位置向发缘下压的比例。越大越深，实际位置受安全区和逐字可见率约束 |
| 大标题最低可见率 | `title.minVisiblePerGlyph`，任一字低于门槛时会试其他高度 |
| 副标题 | `subtitle.y`、`size`、`color`、`font`、`fontIndex`、`lineHeight`。每行字身左边界默认对齐大标题，可用 `subtitle.xOffset` 按裁切宽度的比例整体右移。副标题字身底部留白至少等于大标题字身顶部留白 |
| 阴影 | 两段文字均沿用[原封面阴影](../../工具/封面版式.json)的 60% 不透明度、30px 高斯模糊和 (7.3, 5.1)px 偏移，按裁切宽度相对原模板 1917px 缩放。可在 `shadow` 覆盖相应字段 |

```sh
node 工具/穿插封面/render.mjs '本期/原照.jpg' '本地封面' \
  '只改标题，复用同一张人像蒙版' '本期/封面_v2' --config '本期/版式.json' --render-only
```

- 以原始照片字节和模型名索引蒙版，缓存默认位于 `~/.cache/rocc-edit/cover-masks/`，可用 `--cache-dir` 指定别处。改文案、排版和比例会复用同一蒙版。 `--render-only` 在没有可用蒙版时立即提示，不启动模型。
- 发缘精修后将灰度 PNG 另存，白色代表前景、黑色代表背景，与校正方向后的照片尺寸一致。重渲染命令加 `--mask '本期/精修蒙版.png'`；也可直接传入上次导出的 `alpha-mask.png`。
- 人像模型效果不合适时，首次切换使用 `--model birefnet-general`，保持同一张原照并换新版本目录。两种模型缓存独立。实际选用的模型和蒙版来源见 `report.json`。
- “无法保留头部”时改用更宽松的比例。“无法同时实现穿插和保留字形”时尝试更宽的头顶留白，或调整大标题的横向位置、字号和蒙版。字体缺字时改用覆盖该字的字体。“三行放不下”时缩短副标题。
- 脚本向标准错误输出抠图、缓存、自动重排和导出日志，标准输出是检查报告 JSON。可用 `npm test --prefix 工具/穿插封面` 运行合成回归。


## 图 2 验收记录

2026-11-17 在 Apple M4、24 GB 机器上运行。测试文案为“本地封面”，使用图 2 原照。Portrait 版首次推理与套版约 12.8 秒（权重已下载），输出 1179×1572。4:5 改稿用同一蒙版，约 0.6 秒并自动上移标题，输出 1176×1470。General 版也完成首次推理和 3:4 导出。两种模型的 3:4 输出及缓存改稿均通过文字和阴影范围外的 sRGB 像素比对。Portrait 版查看了完整预览与发缘原尺寸局部。另验证 1:1 裁切会自动上移以保留标题，近景的副标题仍可能压到下巴，图 2 采用 3:4 作为成品。
