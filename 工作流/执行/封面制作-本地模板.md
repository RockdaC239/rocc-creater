# 封面制作：3:4 原片抽帧与四字模板

上级：[内容生产工作流](../内容生产.md)。Agent 直接执行，无需用户操作醒图；只制作封面，不发布。

## 当前模板

参考：工作区根目录 `封面参考.jpg`；**宽:高固定为 3:4**，参考和当前输出均为 1917×2556。平台目标为用户指定的小红书、抖音封面；不因此改变口播视频本身的 9:16 比例。

当前为四字大标题：上排两字、下排两字，中间留出人脸区域。无界黑字体来源为作者的[公开仓库](https://github.com/maoken-fonts/unbounded-sans)，当前使用 `UnboundedSans-Regular.otf`。缓存到 `~/.cache/rocc-edit/`，字体和项目图片不混入工具源码。

字号不能直接把醒图的 104 当作 104px。参考图的实际字身区域为：

| 字格 | 参考字 | 左上 → 右下（半开像素边界） |
| --- | --- | --- |
| 左上 | 生 | (179,298) → (855,834) |
| 右上 | 意 | (1031,298) → (1736,853) |
| 左下 | 惨 | (189,1709) → (879,2255) |
| 右下 | 淡 | (1029,1704) → (1741,2261) |

文字颜色按用户最新确认使用纯白 #FFFFFF；参考图取样色 #F2EEED 不再作为默认值。坐标和映射保存在[封面版式.json](../../工具/封面版式.json)，不能只凭目测重新摆放。渲染器从无界黑生成 SVG 字形路径，不依赖系统字体回退。后续替换四字标题时沿用字格对应的字体变换，不把“一”等短笔画强行拉成整格高度。

用户提供的醒图原设置另行保留：无界黑、大小104、阴影黑色、透明度40、模糊85、距离5、角度−35。当前阴影透明度按透明40%（不透明60%）解释；SVG 高斯模糊 stdDeviation=30、偏移 (7.3,5.1) 为视觉换算初稿，**尚未验证与醒图阴影逐像素相同**。字体轮廓重合度约 97.9%–98.8%，布局边界回归误差不超过1px；不得将这些结果描述成整张图已逐像素1:1复刻。收到用户反馈后只调整对应配置并另存新版。

## 执行步骤

1. 读取本期素材与工程，选取无口误表情、双眼自然、构图合适的时间点。从**原片**抽帧，避免成片已有字幕污染封面。HDR 使用 `工具/原生抽帧.swift` 的原生 SDR 显示抽帧，不对原视频转码。原始抽帧另存。
2. 采用3:4画布，背景保持比例裁切；当前为居中裁切，先检查人脸是否被不合理裁掉。裁切只用于封面，不改变原视频。不能拉伸背景凑比例。
3. 确定四字文案，按固定字格渲染；其他字数暂不自动缩小或改布局，需要单独校准。
4. [封面渲染器](../../工具/封面渲染.py)同时输出 PNG 成图和 SVG 可复用工程；字体已转路径，SVG 可在没有字体的环境中查看。输出使用新版本名，不覆盖原图或旧封面。
5. 检查比例、字格边界、字形、间距、文字颜色、阴影和脸部留白。初次校准要对照参考图，不将背景不同导致的观感差异误当成文字排布错误。阴影仍待确认时明示，不自动认定默认配置已经验收。

## 命令

依赖：Python 的 Pillow、fonttools、resvg-py；原生抽帧使用 macOS Swift/AVFoundation。首次准备字体：

```sh
curl -L --fail https://cdn.jsdelivr.net/gh/maoken-fonts/unbounded-sans@main/fonts/UnboundedSans-Regular.otf -o ~/.cache/rocc-edit/UnboundedSans-Regular.otf
```

字体下载完成且能够加载后才能渲染；原字体授权为 OFL，字体来源及授权副本留在缓存或项目记录。工作区根目录执行：

```sh
swiftc 工具/原生抽帧.swift -o ~/.cache/rocc-edit/原生抽帧
~/.cache/rocc-edit/原生抽帧 原视频.MOV 16 本期/原始抽帧.png
python3 工具/封面渲染.py 本期/原始抽帧.png 生意惨淡 本期/封面_v1.png
python3 -m unittest discover -s 工具 -p 'test_*.py'
```

首次校准产物在 `内容项目/2026-10-30_封面模板校准/`，包含原始抽帧、PNG/SVG 试作、透明文字层、参考对照及校准报告。背景使用现有口播素材抽帧；“生意惨淡”仅用于复核参考排布，不代表该期最终发布文案。当前已完成3:4模板与排布校准，整体视觉及阴影仍待用户确认。
